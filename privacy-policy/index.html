THE CURATED FIND PIN PUBLISHER

Privacy Policy

Effective date: 7 November 2026

The Curated Find Pin Publisher is a privately operated, independently developed personal-use application. It is used exclusively by its developer to prepare and publish original Pins to the developer's own Pinterest account through Pinterest's official API. It is not offered to the public, distributed as a service, or used to manage third-party Pinterest accounts.

It is operated by the GitHub user RomanGOW. "The Curated Find" is a project name, not a registered company. It is not affiliated with Pinterest, Inc.

1. Information the application handles

  • OAuth access and refresh tokens issued by Pinterest for the developer's own account;
  • Pinterest account and board information returned by the API, used to choose a destination board;
  • Pin content created by the developer: images, titles, descriptions and destination links; and
  • ordinary operational logs of the application.

The application never asks for or collects a Pinterest password or session cookie. Access is authorised only through Pinterest OAuth.

2. Where information is stored

OAuth tokens are stored locally on the developer's computer, in the application's local configuration or database. They are not stored on any server operated by this project and are never placed in website files, public source-code repositories or ordinary logs.

Pinterest account and board information is requested from the API when needed and is not kept in a permanent database. Pin drafts and original images are stored locally on the developer's computer.

3. How information is used

Information is used only to authorise access, choose a board, and publish Pins that the developer has individually selected and explicitly chosen to publish. When a Pin is published, its content is sent to Pinterest, which handles it under its own terms and privacy policy.

Information from the Pinterest API is not sold, shared with third parties, combined with other people's account data, or used to train or improve any AI or machine-learning model. The application does not scrape Pinterest and does not automate follows, comments, messages or other engagement.

4. Deletion and revoking access

The developer can delete the locally stored tokens at any time and can revoke the application's access in Pinterest account settings. Deleting local files does not remove Pins already published to Pinterest; those can be deleted on Pinterest.

5. This website

This website is hosted by GitHub Pages and contains no forms, analytics or cookies set by this project. GitHub may process technical visitor information such as IP addresses; see the GitHub Privacy Statement.

6. South African law

This project is operated from South Africa and aims to handle personal information in line with the Protection of Personal Information Act 4 of 2013 (POPIA).

7. Contact

Privacy and project enquiries can be directed to the developer through the RomanGOW GitHub profile. Please do not submit confidential personal information, passwords or access tokens through public GitHub discussions or issues.
