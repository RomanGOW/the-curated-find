The Curated Find Pin Publisher is a personal-use application developed to prepare and publish original Pins to the operator's own Pinterest account through Pinterest's official API.

Independently developed by RomanGOW
01 / PURPOSE

Made for one account

The application is currently developed for the operator's personal workflow. It is not offered as a public service or multi-user platform.

02 / AUTHORISATION

Official OAuth access

Account access is authorised through Pinterest OAuth. The application does not ask for or collect a Pinterest password or session cookie.

03 / LOCAL CREDENTIALS

Kept on the operator's device

Pinterest API credentials and tokens are intended to be stored locally on the operator's computer, not in a server operated by this project.
